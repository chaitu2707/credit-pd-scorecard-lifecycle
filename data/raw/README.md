# Raw data

Place the Lending Club accepted loans file here, unchanged:

    data/raw/accepted_2007_to_2018Q4.csv

Source: Lending Club accepted loans data, 2007 to 2018 Q4 (public release, also hosted on Kaggle).
The data dictionary (LCDataDictionary.xlsx) should sit alongside it for reference.

The raw file is not committed to Git. Only this README is tracked.
